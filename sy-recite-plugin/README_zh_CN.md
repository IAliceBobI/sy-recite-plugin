# sy-recite-plugin（仿写练习）

任意文档的读后仿写练习闭环：**批注变色 → 抽取仿写 → 对比原文 → 默写查错 → AI 判卷**。

读了一篇好文章，光划线记不住——把想练的句子标出来，合上原文凭记忆复述，再和原文逐题对比找差距。本插件把这套流程搬进思源笔记：任意文档、无需特殊格式，批注即练习题。

## 八大功能

- **批注变色**：进入仿写模式后，用思源原生 mark 高亮标记想练的句子，已批注句自动变色、与未批注一眼可分
- **AI 拆分**（Pro）：不知道从哪下笔？让 AI 通读全文、按叙事节拍自动插入锚点批注——复述锚点（节拍 + 名词关键词，只提词不泄行文）/ 仿写锚点（节拍 + 技法讲解）/ 方向锚点（剧情走向 + 情绪线）三种文风三选一；重跑删旧插新，手写的批注永远不动，已拆过的节拍自动避开；走思源已配置的 AI（设置 → AI，与 AI 判卷同款），判卷也会认得 AI 锚点按「技法达成 / 方向级」点评
- **抽取仿写**：一键按批注生成「抽取」子文档，每条批注一处复述位，合上原文开写
- **对比文档**：复述完成后一键生成「对比」子文档，左原文右复述、每题一张卡片，差距一目了然
- **默写查错**：弹窗逐字比对原文与复述——中文按字、英文按词，写错红删除线、漏写绿下划线，底部给出差异统计（标点差异不计），即看即走不写入文档
- **AI 判卷**：用思源已配置的 AI（设置 → AI）当场逐题点评，多标准模板自动区分「背诵级逐句对照」「骨架级结构分析」与「联想级创意评价」，结果流式写入对比文档末尾，可反复判；判官语气三档可调（文判·鼓励 / 中立 / 武判·严厉，设置面板切换）；也可一键复制判卷提示词粘给任意 AI
- **判卷小宠物**（桌面端）：浮条左上常驻一只小宠物陪你练——平时眨眼呼吸，鼠标掠过会兴奋摇摆，点它有惊喜——豆豆、雪团蹦跳眯眼笑冒小爱心，小盼、博士、豆芽各有专属变身演出（展翅全身像 / 书页飞舞流苏甩起 / 鼓腮喷小火苗）；AI 判卷时它原地打盹守着，出分瞬间放大弹出按成绩摆表情（好评眯眼笑、差评撇嘴掉泪），还会跟着判官语气变戏法（文判好评举爪打气、武判差评叉腰瞪眼）；默认免费，可在设置中关闭
- **联想练习**：批注写「联想：树 · 安全带 · 考试」这样的题目，抽取后自由联想写作，AI 按联想级标准评创意——从三个词长出一个故事

## 四种练法

仿写三种按离原文的远近分级，可以混着来：**背诵级**（逐句还原，练用词精度）、**大意级**（凭记忆写大概，练叙事节奏）、**骨架级**（拆出结构、换掉情节，写同构不同事的新片段）。好句子用背诵级抠细节，好桥段用骨架级学结构。第四种**联想级**干脆离开原文：批注写「联想：词一 · 词二 · 词三」，凭几个词自由联想写作，AI 评你的联想力——词是否都用上、连接巧不巧、想得远不远。

## 入口

原文、抽取、对比三类文档各有一条常驻浮条，按钮带图标（桌面端图标 + 文字、移动端纯图标），标题行/顶栏有 ✕ 可临时收起（切换文档自动恢复）；桌面端浮条可自由拖动，移动端自动吸附为顶部工具栏下方的横滑操作条（与渐进学习顶栏同屏时自动错开）。进出仿写模式的三入口：**顶栏笔形图标**（默认显示，可在设置中关闭）、命令面板、右键菜单「插件」子菜单。

五个功能命令的默认快捷键如下，均可修改——点击插件设置「快捷键」节的键帽（或思源 设置 → 快捷键）按下新组合即可换键，免重启即时生效：

| 功能 | Mac | Windows |
|---|---|---|
| 进入 / 删除仿写模式 | ⌥⌘K | Alt+Ctrl+K |
| 抽取 | ⌥⌘Q | Alt+Ctrl+Q |
| 对比 | ⌥⌘G | Alt+Ctrl+G |
| 复制判卷提示词 | ⌥⌘P | Alt+Ctrl+P |
| 重新写 | ⌥⌘C | Alt+Ctrl+C |

## 上手四步

1. 打开任意文档，点顶栏笔形图标进入仿写模式
2. 用 mark 高亮标记要练的句子（已批注句自动变色）；不知道怎么拆节拍？浮条点「AI 拆分」（Pro）让 AI 先插锚点起步——拆分本身也是练习，熟练后建议自己写批注
3. 浮条点「抽取」，在生成的抽取文档里凭记忆复述
4. 浮条点「对比」看差距、「默写查错」逐字校对，再点「AI 判卷」收点评

详细说明（含浮条按钮逐个解释与完整示例）：插件设置页 →「使用说明」。
