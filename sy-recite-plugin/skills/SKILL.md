# 仿写练习（recite）· AI 工具说明书

给 AI 助手（思源内置 agent / 任意 MCP 客户端）的操作指南。仿写练习=读后重写训练：用户读一篇文章，凭锚点提示默写复述，再对照原文、AI 判卷。你可以帮用户**读文出题、装配练习现场、查询练习数据做精评**。

## 工具入口

单一工具 `recite`（内核注册全名形如 `plugin__sy_recite_plugin__recite__…`），按 `action` 分流：

| action | 参数 | 费用 | 用途 |
|---|---|---|---|
| `read_origin` | `docID` | 免费 | 读原文档顶层块流（块 id+摘要+既有锚点+是否仿写模式）——出题前的第一步 |
| `list_exercises` | 无 | 免费 | 列全部练习现场（原文/抽取文档/标题/时间） |
| `get_grade` | `docID`（原文/抽取/对比文档 id 均可） | 免费 | 查 AI 判卷结果（判官档/成绩/遗漏点/全文点评） |
| `pro_status` | 无 | 免费 | 查激活态（决定要不要推荐 build_drill） |
| `build_drill` | `originID` + `mode` + `anchors` | **Pro** | 一键装配练习现场（详见下） |
| `echo` | `message?` | 免费 | 通道自检 |

## 典型工作流：AI 出仿写题

1. **拿文档 id**：用户给文档链接/id，或你用思源自带工具（搜索/SQL）定位。
2. **read_origin** 通读全文（每块带 id 与截断摘要；`kind` 说明块身份：original=原文 / note=用户手写批注 / ai-anchor=既有 AI 锚点）。
3. **你来做摘要拆点**（这是你的工作，插件不代劳）：通读理解，按叙事节拍设计 5~15 个锚点——文风三选一（`mode`），格式见 `recite/anchors.md`。锚点插在节拍收尾的块之后（`after`=该块 id）；最后一个锚点收住全文结尾。
4. **build_drill** 传入锚点数组，插件完成装配：原文进仿写模式 + 插入锚点批注 + 重建抽取文档（锚点+空写位）。返回抽取文档 id——告诉用户去那里写复述。
5. 用户在前端写完复述、点对比/判卷后，你可用 **get_grade** 拿判卷结果做精评复盘。

## Pro 行为（怎么向用户转述）

`build_drill` 是 Pro 功能（与插件 UI 的「AI 拆分」同一能力同一门）。未激活时调用会返回引导文案（`needActivation: true`）——原样转述给用户即可：激活后即可使用，AI 判卷仍免费。查询类 action 永远免费。

## 注意

- 同一文档重复 `build_drill` = 整场重建（旧 AI 锚点删除重插、抽取文档重建），用户手写批注永不被动；AI 重试安全。
- 含「这段练」靶块的文档暂不支持 MCP 装配（返回文案会说明）。
- 锚点格式细节与文风指引：`recite/anchors.md`。
